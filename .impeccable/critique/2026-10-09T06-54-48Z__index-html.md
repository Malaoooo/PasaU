## Overall Impression
Polished and coherent; the handover section is genuinely good. But the campus is nowhere, the School filter and search both come up empty first try, and the first featured item is "test offer". Biggest opportunity: campus-first (school on every card, campus switcher, search that understands "textbooks").

## What's Working
- The handover story: four plain steps with the code as the visual object ("No shipping and no home addresses", "No code, no sale").
- Filter feedback: removable chips, Clear all, empty states with a reason and one action (index.html:594-634), live match count, recent searches.
- Accessibility: native dialogs returning focus, skip link, carousel pause, reduced motion, shortcuts with off switch, Accessibility panel, 44px targets.
